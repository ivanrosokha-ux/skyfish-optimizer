# Лабораторна робота №2: Власна ідея веб-додатку. Ч2 — дизайн
## Проєкт: «SkyFish Optimizer» (Hypixel SkyBlock Fishing Assistant)

Веб-застосунок на базі **React 18** та **Vite** для аналітики та оптимізації ігрового спорядження у режимі **Hypixel SkyBlock (Minecraft)**. Розраховує найбільш вигідні покращення за метрикою питомої вартості *Cost per +1 Stat*.

---

### 📚 Звітна документація проєкту (`docs/`)
* **[Звіт з Лабораторної роботи №1 (.docx)](./docs/ЗВІТ_Лабораторна_1_Росоха.docx)** — повний звіт за стандартами УжНУ.
* **[Звіт з Лабораторної роботи №2 (.docx)](./docs/ЗВІТ_Лабораторна_2_Росоха.docx)** — дизайн-система, UI-макети, посилання на Git/PR.
* **[Технічне завдання проєкту (ТЗ v2.1)](./docs/TECHNICAL_SPECIFICATION.md)** — інженерна специфікація.
* **[Дизайн-макети сторінок (UI Mockups)](./docs/mockups/)** — оригінальні макети інтерфейсу.

---

### 🛠 Технологічний стек
* **Frontend:** React 18 (SPA), Vite
* **Стилізація:** Tailwind CSS (темна RPG-тема)
* **Маршрутизація:** React Router v6
* **Стейт-менеджмент:** Zustand
* **Автентифікація:** Firebase Auth
